# Three-Tier DBMS Mini Project

This project demonstrates a simple three-tier database architecture using Python.

## Project Structure
- **main**: User interface layer (runs the program)
- **src**: Business logic layer
- **data**: Database access layer

## How It Works
1. The program starts in `main/app_ui.py`
2. It calls logic functions from the `src` folder
3. The `src` layer communicates with the database through the `data` layer

## Technologies Used
- Python
- MySQL (simulated connection)
- GitHub

## Purpose
This project was created as a mini DBMS project to understand how three-tier architecture works in practice.
